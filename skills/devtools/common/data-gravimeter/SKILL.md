# 数据引力仪

把任意数值表格变成一张「引力关系图」+ 一段人话解读。核心算法源自已验证的「引力确定浮点关系」技术（大模型注意力跳过率99.2%、精度损失0），把「判断浮点与问题是否有语义关系」的引力判据迁移到数据分析场景：**不计算所有相关性，只计算有语义引力关系的列对**。

## 何时使用

用户说出下列任意一句时：
- 「帮我分析这份数据/CSV/表格，看哪些指标有关系」
- 「这些列之间有什么隐藏关联？」
- 「哪个因素影响销量/涨粉/转化/成绩？」
- 「帮我找最优区间/最优值」（如最佳定价、最佳运动量、最佳投放）

## 使用方法

### 步骤一：拿到数据
用户提供CSV文件路径，或把数据粘贴到对话里（保存为临时CSV再分析）。数据要求：表头行 + 至少3行数据 + 至少2个数值列。分隔符支持逗号/分号/制表符/竖线。

### 步骤二：运行引力仪
```bash
node 数据引力仪.mjs <数据文件.csv> [--阈值 0.35] [--仅图] [--JSON]
```
- 默认阈值0.35：关系图更宽松；用户想「只看最关键的」时用 `--阈值 0.5`
- `--JSON`：需要机器可读结果时使用

若用户粘贴的是数据而非文件，先写入临时CSV文件再执行。

### 步骤三：呈现结果
把输出的两段内容直接展示给用户：
1. **关系图**：ASCII引力场图，`⇄`正向 `⇆`反向 `↯`门槛建制，强度条和引力值
2. **人话解读**：一眼看懂 + 前三强关系 + 建议动作

然后根据用户的数据领域，补充你自己的业务洞察（引力仪给出的是统计关系，你负责解释业务含义）。

## 关系类型说明（解读时使用）

| 类型 | 箭头 | 含义 | 人话模板 |
|------|------|------|----------|
| 线性吸引 | ⇄ / ⇆ | 一个升另一个跟着升降，像绑在同一根绳上 | 适合互相预测 |
| 非线性共振 | ⇄ / ⇆ | 同步起落但不成正比 | 存在门槛效应，分段看更准 |
| 门槛建制 | ↯ | U型/倒U型：存在最优点，过了就反转 | 别线性加码，找最优区间 |

**引力跳过率**是本Skill的招牌指标：被跳过的列对不是「没关系」，是「无语义引力关系」——就像引力判据跳过99.2%的注意力计算一样，跳过是为了让真关系不被噪声淹没。

## 边界与诚实性

- 相关≠因果：解读时始终提醒用户「引力关系是共变证据，不是因果证明」
- 行数<10时提示「样本偏少，结论仅供参考」
- 门槛建制要求数据覆盖完整区间（只有上升段会被误判为线性）——数据单边时主动提醒
- 非数值列（文本、分类）自动排除，不参与引力计算
